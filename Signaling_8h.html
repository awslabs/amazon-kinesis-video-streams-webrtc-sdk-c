◆ SIGNALING_CURRENT_THREAD_ID

#define SIGNALING_CURRENT_THREAD_ID ( )
Value:
((SIZE_T) GETTID())

Internal structure tracking various parameters for diagnostics and metrics/stats Identity of the calling thread, used only to detect freeSignaling() being called from one of the signaling client's own threads. GETTID() is not usable for this on Windows: kvspic implements it as GetCurrentThread(), which returns the same pseudo-handle on every thread. GetCurrentThreadId() is unique among live threads; on POSIX GETTID() is pthread_self(), which already is.
