#define LOG_CLASS   "DtlsInStun"

DTLS-in-STUN (SPED, draft-uberti-tsvwg-warp section 4.2) controller

Follows libwebrtc's DtlsStunPiggybackController, the implementation browsers interoperate with: the peer supports SPED if its first authenticated check carries either attribute, a new DTLS flight replaces the embedded one, and embedding ends once the local handshake is done and the peer has acknowledged the last flight or sent application data.
