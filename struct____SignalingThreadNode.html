Detailed Description

Stack-allocated marker a signaling-owned thread links into one of the SignalingClient lists for as long as it runs (pActiveReceiveWorkers for receiveLwsMessageWrapper(), pActiveReconnectThreads for reconnectHandler()), so freeSignaling() can detect being called from a callback on that thread.
