◆ dtlsSessionKeepEarlyClientHello()

STATUS dtlsSessionKeepEarlyClientHello ( PDtlsSession pDtlsSession,
PBYTE pData,
UINT32 dataLen )

Keeps a ClientHello that arrived before dtlsSessionStart() for the session to answer when it starts, replacing one kept before (RFC 8842 section 5.2: the answerer may send it as soon as its own ICE is ready). Call with sslLock held, before the session started.

Returns
- STATUS - STATUS_SUCCESS if the packet was kept, STATUS_SSL_PACKET_BEFORE_DTLS_READY if it does not start a ClientHello and is dropped, STATUS_NOT_ENOUGH_MEMORY if it could not be copied (one kept before stays), STATUS_NULL_ARG
