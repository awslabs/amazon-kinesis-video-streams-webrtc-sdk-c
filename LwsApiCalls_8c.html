◆ getWssUpgradeFailureResult()

SERVICE_CALL_RESULT getWssUpgradeFailureResult ( PSignalingClient pSignalingClient,
PVOID wsi )

Maps a failed WSS upgrade to a service call result. lws keeps the response headers attached until after the connection error callback, so a 401/403 can be checked against its Date header: when the upgrade was signed with a stale clock skew correction, the measured one is recorded and the connect is retried in place.

◆ parseIceConfigResponse()

STATUS parseIceConfigResponse ( PCHAR pResponseStr,
UINT32 responseLen,
UINT8 maxIceConfigs,
PIceConfigInfo pIceConfigs,
PUINT32 pIceConfigCount )

Parses ICE configuration from a JSON response string. If there are more ICE configurations in the string than maxIceConfigs, we will only parse up until maxIceConfigs.

Parameters
[in]pResponseStrJSON string containing ICE server configuration.
[in]responseLenLength of the JSON string (excluding null-terminator).
[in]maxIceConfigsMaximum number of ICE configurations the array can hold.
[out]pIceConfigsPointer to array of IceConfigInfo structures to be populated.
[out]pIceConfigCountPointer to receive the number of ICE configurations parsed.
Returns
STATUS code of the execution:
  • STATUS_SUCCESS: Successfully parsed ICE configuration.
  • STATUS_NULL_ARG: Invalid NULL argument provided.
  • STATUS_INVALID_API_CALL_RETURN_JSON: Malformed JSON or missing required fields.
  • STATUS_SIGNALING_MAX_ICE_URI_COUNT: Too many URIs in configuration (more than MAX_ICE_CONFIG_URI_COUNT).

◆ recordClockSkewCorrection()

INT64 recordClockSkewCorrection ( PSignalingClient pSignalingClient,
UINT64 serverTime,
UINT64 nowTime )

Records the clock skew measured from a response Date header as the correction for all later requests. The measurement is always against the raw device time, so a device clock that gets fixed resets it to 0.

Returns how far off the signing time of the last signed request was. Beyond MIN_CLOCK_SKEW_TIME_TO_CORRECT, re-signing that request with the new correction can succeed.
